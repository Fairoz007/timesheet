Time Management Tool
A simple, browser-based Time Management Tool built with only HTML, CSS, and JavaScript. This tool helps users to log, manage, and track their working hours on a daily basis. It’s designed to be lightweight and easy to use, making it perfect for freelancers, students, or anyone looking to manage their time efficiently.

Features
Add Time Entries: Add daily time entries with task details.
Edit & Delete Entries: Update or remove logged entries easily.
Daily Overview: View total hours logged for the day.
Simple & Intuitive Interface: Easy-to-use interface with responsive design.
Local Storage Support: Saves data to local storage so your logs persist after a page refresh.

Usage
Open the tool in your browser:
Once opened, you’ll see a simple interface to add time logs.
Log a Task:
Enter the task name, start time, and end time.
Edit or Delete Entries:
Each entry can be edited or deleted using the corresponding buttons.
View Daily Summary:
At the bottom, you can see the total time logged for the day.
